# Lógica simbólica

La lógica como sistema formal y como herramienta de cómputo: sintaxis y semántica, deducción natural, lógica de predicados, corrección y completitud, resolución y Prolog, SAT y SMT, lógica modal y temporal, verificación de modelos y asistentes de demostración.

**Ver en línea:** https://aaramirez.github.io/logica-simbolica/

Este repositorio solo tiene el sitio generado. El curso está en preparación: la tabla de contenido ya está publicada para revisión.
